# Changelog - 2026-07-11

## Summary
Fixed the package load failure on n8n 2.x (`Cannot find module 'axios'`) by removing axios entirely:
Raw Mode now goes through n8n's `httpRequest` helper. Updated the Docker test environment.
Prepared release 2.8.1.

## Notes
Root cause: axios was only a devDependency and `helpers/http.ts` did a top-level `require('axios')`,
relying on n8n's bundled axios. n8n 2.x isolates its dependencies (pnpm layout) and no longer exposes
them to community nodes, so the whole package failed to load right after install/redeploy.
Verified: 734 unit tests pass; simulated npm install inside the n8n 2.29.10 container loads the node;
end-to-end run against the pre-prod PrestaShop works in both JSON and Raw modes (raw output is the
unparsed XML string).
UI integration suite (`tests/ui/run-integration-tests.py`) on n8n 2.29.10: 88/93 passed (94.6%).
The 5 failures are unrelated to the axios fix: combinations/tags/product_options lists are empty on
the pre-prod shop (data-dependent), and images getById/search are known limitations of the generic
test script (no ID provided; search without filter is rejected by design).
